## Co je to?

Toto je full-stack e-commerce šablona, která poskytuje tři věci:

| Co | Kde | Účel |
|------|-------|---------|
| **Administrátorský web** | `/website` | CMS založený na prohlížeči pro správu všeho |
| **Mobilní aplikace** | `/mobile` | Aplikace pro zákazníky vytvořená v React Native |
| **Sdílená logika** | `/shared` | Služby, typy a i18n používané oběma |
| **Databáze** | `/supabase` | PostgreSQL přes Supabase - schéma + migrace |
