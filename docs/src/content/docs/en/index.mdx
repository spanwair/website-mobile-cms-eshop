## What is this?

This is a full-stack e-commerce template that ships three things together:

| What | Where | Purpose |
|------|-------|---------|
| **Admin Website** | `/website` | Browser-based CMS for managing everything |
| **Mobile App** | `/mobile` | React Native app for customers |
| **Shared Logic** | `/shared` | Services, types, and i18n used by both |
| **Database** | `/supabase` | PostgreSQL via Supabase - schema + migrations |
