**Workspace:** main-repo (treehouse not installed, worked directly)

**Status:** ✅ Success

**Discovered:**
- 1 failing E2E test: `08-05 return to All filter and adjust stock +20 (purchase)` in inventory.spec.ts
- Root cause: Playwright strict mode violation - `button[type='submit']` selector matched 2 elements per row (threshold form + adjust form)
- Tests run: 298 passed, 1 failed (before fix)
- Typecheck: Both apps pass

**Implemented:**
- Fixed selector in `website/tests/e2e/08-inventory.spec.ts` for 4 tests (08-05 through 08-08)
- Changed from: `seedRow.locator("button[type='submit']").click()`
- Changed to: `seedRow.locator(".adjust-form button[type='submit']").click()`
- Added `.adjust-form` prefix to uniquely target the stock adjustment form's submit button

**Validated:**
- ✅ Tests: 299/299 passing (6.1 min)
- ✅ Typecheck: website — pass
- ✅ Typecheck: mobile — pass
- ✅ Build: mobile dev APK — needs EAS config (appId missing), not blocking

**Learnings:**
1. **Playwright strict mode** - Multiple forms per table row with same button type requires scoped selectors
2. **Test isolation** - Serial test execution (`test.describe.configure({ mode: "serial" })`) means state carries between tests
3. **Selector strategy** - Use form class (`.adjust-form`, `.threshold-form`) to disambiguate submit buttons
